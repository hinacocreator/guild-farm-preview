### 棚卸しで確認した最大の問題（運用修正との不一致）

**現行ページは「相談・面談を経ないと申し込めない」構造になっている。**
該当箇所は次の4つで、すべて TUNE または CUT の対象。

| 箇所 | 現状の文言 | なぜ問題か |
| --- | --- | --- |
| h1 | 「まず、話を聞くところから。」 | ページの最上位の宣言が「まず相談」。運用修正と正面から矛盾する |
| sub | 「はじめから滞在を決めている必要はありません。」 | 決めている人が読む場所がない。**入口Bだけがある状態** |
| STEP 01 | 「問い合わせる」 | 申し込みではなく問い合わせが第1歩として固定されている |
| STEP 02 | 「オンラインなどで相談する」 | 相談が**必須ステップ**として番号付きで並んでいる（＝面談必須と読める） |
| ClosingCta | 主CTA「滞在について相談する」のみ | 最終CTAに申し込み導線がない。相談しか出口がない |

加えて:

- **ページの第一目的（申し込みたい人を申し込みまで案内する）に対応する導線が1つもない。**
  サイト内のCTAは全て `contactHref`（mailto・件名「GUILD Farmの滞在について」）で、
  「申し込む」ためのリンクが存在しない。
- **/plans/ と /life/ の再掲が多い。** access 章（滞在先2か所・体験の場所3か所）は
  `plans.ts` の `access` / `imaichi` と `life.ts` の `places` にほぼ同文で存在する。
- **章が5つ＋脚注3行と長い。** 指示書4の「長大にしない」に反する。
