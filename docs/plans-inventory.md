棚卸しで確認した問題点:

1. **比較できない。** 2つのプランが左右に並んではいるが、項目の並び順が揃っておらず、
   片方にしかない情報（受け入れ時期・人数）がある。スマホでは縦に長く積まれ、
   上下にスクロールしないと違いが分からない。
2. **滞在先の情報が3か所に散っている。** 01（滞在先の1行）・03（三津浜のグレードアップ）・
   05（今市の写真と設備）・07（Wi-Fi と周辺）。「どこに泊まって、どんな暮らしになるのか」が
   1か所で読めない。
3. **含まれるものと設備が混ざっている。** 02 の一覧に「自分の部屋」「共用のキッチンと、道具」
   （＝施設設備）と「考えるための時間」（＝体験として得られるもの）が同列に並んでいる。
4. **実費の情報が 02 の note・04 の項目・08 のFAQに分散**しており、
   「結局いくら別に要るのか」が読み取りにくい。
5. **三津浜の宿（1週間プランの滞在先）に、写真も部屋の説明もない。**
   01 では畑の写真（`expHarvest`）が三津浜の宿の位置に当たっており、
   誤読の余地がある（今市の写真は使っていない＝この点は問題なし）。
6. **h1「この料金で、できる暮らし。」と sub「家賃ではなく、暮らしそのものの会費だと思っています。」**
   は世界観コピーで、指示書4（H1「プラン・料金」・思想を語らない）と合わない。
   sub は phase3b ルール2の「Aではなく、B。」の形でもある。
