# 「松井について」（/owner/）棚卸し（2026-09-16・実装前）

指示書: `owner-brand-edit.md`。
現状の `src/content/owner.ts` の全項目と、2026-09-15 の ABOUT ブランド編集で ABOUT から
このページへ移設した情報（`CHANGELOG-phase3a.md`「ABOUTブランド編集」2章）を項目ごとに分類しました。

**分類の定義**
- **KEEP** … そのまま残す（章の中身は変えない）
- **MOVE** … 新しい章立てに合わせて別の章へ動かす（内容は変えない）
- **MERGE** … 重複しているものを1か所に統合する
- **CUT** … 削除する。**編集文（AIによる意味づけ・重複の地の文）だけ**が対象
- **FACT CHECK** … 一次情報との照合が必要

**大原則**: 一次情報（松井さんの原文引用・確認済みの出来事）は、ページ整理を理由に削除しない。
CUT できるのは編集文だけ。

出典の略号:
- **原文** … `matsui-story.txt`（「どうしてこのシェアハウスを始めたのか」全文）の該当箇所
- **F6** … `feedback-matsui-1.md` の F6（伊予柑）
- **確定コピー** … クライアント確定済みのコピー（HOME等で使用中）
- **編集** … 制作側が書いた地の文（＝一次情報ではない）
